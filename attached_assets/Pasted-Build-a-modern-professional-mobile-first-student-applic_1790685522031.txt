Build a modern, professional, mobile-first student application called **AttendX** for college/university students.

The main purpose of AttendX is to help students manage **attendance, class routine, study time, exams, notes, PYQs, results, syllabus, productivity, notifications, and student community** from one app.

## 1. APP TYPE AND DESIGN

Create a clean, modern, professional **mobile-first responsive web app / PWA** that works smoothly on Android phones, tablets, and desktop.

Use a simple student-friendly UI.

Design requirements:

* App name: **AttendX**
* Professional blue/white modern theme
* Rounded cards
* Clean dashboard
* Bottom navigation for mobile
* Sidebar navigation for desktop
* Smooth animations
* Dark mode + light mode
* Responsive design

# 3. COLLEGE LOCATION LOCK SYSTEM

Create a **College Location Lock** feature for attendance.

During setup:

Student clicks:

**"Set My College Location"**

The app requests location permission and saves the student's college location.

Save:

* Latitude
* Longitude
* College name
* Allowed radius

Default radius can be **100–200 meters**, but allow the student to configure it.

Display:

**College Location: Locked**

Example:

College: Government Engineering College Buxar
Location: Saved
Status: Active

The student should be able to see the saved location on a map.

Allow:

* Set location
* Update location
* Re-center location
* Enable/disable location monitoring

IMPORTANT ATTENDANCE LOGIC:

When a scheduled class is about to start:

### Case 1 – Phone Location is OFF

Show notification:

"Your location is turned off. Turn on location to help verify your class attendance."

Also show a warning inside the app.

### Case 2 – Phone Location is ON

Do NOT send the location-off warning.

The app can check whether the student is inside the saved college radius.

Display:

Inside college radius → "College Location Verified"

Outside college radius → "You are outside the saved college location"

Do not automatically mark attendance without student confirmation.

# 37. ATTENDANCE LOGIC – IMPORTANT

Implement this carefully.

When class starts:

1. Check phone/browser location permission/state if available.
2. If location permission/location services are OFF:
   show/send location warning.
3. If location is ON:
   silently verify location status.
4. Do not automatically mark attendance.
5. After class end:
   send attendance confirmation notification.
6. Student chooses:
   PRESENT
   ABSENT
   HOLIDAY
7. PRESENT → attendance entry = Present
8. ABSENT → attendance entry = Absent
9. HOLIDAY → no attendance entry
10. Update subject attendance percentage immediately.
11. Update dashboard immediately.

Prevent duplicate attendance entries for the same class/date.

Allow student to view and correct attendance records according to app rules.
